# Verde Urbano Viveiro — Landing page
Site estático: HTML5, CSS3 e JavaScript puro. Sem PHP, banco de dados, Docker ou Bootstrap.

## Estrutura
```
verde-urbano/
├── index.html
├── assets/
│   ├── css/style.css
│   ├── js/script.js
│   └── images/ (logo.png, hero/, produtos/, galeria/, loja/)
├── README.md
└── DEPLOY.md
```

## Executar localmente
Dê dois cliques em `index.html`, ou, na pasta do projeto: `python3 -m http.server 8000` e abra http://localhost:8000

## Logo
Substitua `assets/images/logo.png` (quadrada, ~400x400).

## Fotografias originais
As imagens atuais são ilustrativas. Para trocar, salve a foto **em .jpg com o mesmo nome e na mesma pasta**:
- `images/hero/hero.jpg` — foto principal (de preferência escura e verde; recebe uma camada escura por cima)
- `images/loja/` — sobre, espaco1, espaco2, presentes
- `images/produtos/` — flores, plantas, vasos, frutiferas, suculentas, terrarios, buques (quadradas)
- `images/galeria/` — g1 a g9 (g1, g4, g7 verticais; g2, g5, g9 horizontais)
Recomendado: até ~1600px de largura e ~250 KB cada.

## Textos e links
Edite diretamente no `index.html` (Instagram, endereço, horários).
